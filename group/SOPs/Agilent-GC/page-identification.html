01

Time References & Expected Retention Times

  1. Within the Agilent Method Development software, open the processing method and in the Compounds subsection select Identification to see the screen shown below.
  2. Methane FID and Ar/O₂ are the time references for the other FID and TCD compounds respectively, as denoted by the checked “Is time ref” box.
  3. To associate a known compound with the FID or TCD time reference, select Methane FID or Ar/O₂ respectively.
  4. Exp. RT is the elution time for each compound; it links integrated peaks to their calibration curves based on elution time.
After a column changeElution times must be updated following a change of GC column. The column installation procedure is at agilent.com — install a GC column. After the change, complete a calibration (Section A) and re-identify elution times as described here.
02

TCD Elution Order (PLOT Q Column)

For the TCD with the PLOT Q column, elution order with increasing time is:

Order1234567
CompoundH₂CO₂Ethylene (TCD)Ethane (TCD)Ar/O₂Methane (TCD)Carbon monoxide
  • Validate these elution times via single injections of individual components flowed alone or with Ar; relative peak size correlates with flow composition. Example: 10% CO / 90% Ar displays a much larger Ar peak, which identifies it.
  • For unknown TCD components unavailable from the reactant MFC manifold, refer to the specific column information on the Agilent website for relative elution times.
03

FID Identification by Carbon Number

  1. On the FID, peaks separate by size exclusion: longer-chain hydrocarbons elute later.
  2. Using processed refinery calibration gas data in the Chromatograms tab (top right), correlate the listed concentrations with compound peak size, using size exclusion to isolate compounds of the same carbon number.

    Example: propane and propylene both elute around 5 min. The calibration gas lists propane at 2% and propylene at 0.5%, so the larger peak in the C3 cluster is propane and the smaller is propylene.

04

Assigning & Adding Peaks

  1. To update an elution time, right-click on the peak and click “Assign compound”, selecting the compound and checking “Update expected retention time” as shown below.
  2. If a peak has not previously been identified and corresponds to a previously unlisted component, right-click on the peak and select “Add peak as compound to method” as shown below.
  3. Back in the Processing Method tab (top right), return to Compounds > Identification to find the newly identified peak denoted as “peak at X min”. Label it appropriately and associate it with the Ar/O₂ (TCD) or Methane FID (FID) time reference depending on which signal it was found in.

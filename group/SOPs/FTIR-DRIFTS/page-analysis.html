Section C — FTIR DRIFTS (T6943)

Data Analysis

Splitting the OMNIC series file into individual spectra and exporting to .csv.

Tag: T6943 Instrument: Thermo Fisher FTIR S/N: AUP1710427 Location: G242 Updated: July 2026
On this page
  • Split the Series File
  • Open & Export
01

Split the Series File

  1. Open the series file (.srs) via File > Open, choosing the appropriate file and clicking Open.
  2. With the series file open, go to the Series tab and click Split Series File.
  3. Enter an appropriate name in the Base Name field. To change the save location, click Set Path and select the desired folder.
02

Open & Export Spectra

  1. After splitting, open the individual spectra via File > Open and choose the desired .spa files.
  2. Save these files as .csv for subsequent data plotting and analysis.

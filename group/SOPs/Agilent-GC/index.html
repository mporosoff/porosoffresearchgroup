What This Guide Covers

This guide covers data-side operation of the Agilent 7890 gas chromatograph shared by the 242 and 245 reactor systems: building calibration curves for reactant and product gases, identifying compounds by retention time on the FID and TCD signals, and correcting peak integration. All work happens in the Agilent Method Development / Data Analysis software (OpenLab).

For day-to-day reactor operation and injections, refer to the 242 and 245 reactor SOPs — this guide assumes you already know how to run a Single Sample injection.

Section A

Calibration

Multi-point calibration for reactant gases via the Brooks MFCs, validation checks, and single-point calibration for hydrocarbon products using the refinery calibration gas standard.

 Section B

Compound Identification

Time references, expected retention times, TCD elution order on the PLOT Q column, FID size-exclusion logic, and assigning or adding peaks.

 Section C

Integration Correction

Manual integration of missed or mis-integrated peaks, and tuning the ChemStation integration parameters and timed events.
